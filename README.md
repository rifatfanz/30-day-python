# 30-Day Python Challenge

This repository contains my journey of learning Python from Day 1 to Day 30.
Goal: Build a complete To-Do App by the end of 30 days.

## Progress

### Day 1: Variables, Input, Print
- Learned: `input()`, `variables`, `f-string`
- File: `day-1-variable-input-print.py`
- Description: Takes student's name, department and DOB and prints a profile.


### Day 2: Odd Or Even Game
- Learned: `while loop`, `if-else-elif`, `import random`
- File: `day-2-odd-or-even.py`
- Description: A mini game basic

### Day 3:
- Learned: `While loop`, `operations`
- File: `day-3-calculator.py`
- Description: A simple calculator using while loop and if-elif-else operations.
